# 发布准备

公开视频工作台代码。`.gitignore` 排除本机数据、配置、备份、庄园和游戏模块、历史任务、个人文档及未获再分发授权的 Apple 模型纹理。被忽略的文件仍保留在本机。

公开版本首次运行为空数据库；自行配置 Ollama、转写模型、Dify 和笔记目录。第三方界面模型缺失时，相应模型预览可能不可用。

发布前必须使用干净文件清单构建，检查当前快照与历史。Git 忽略规则不删除历史数据，也不能排除已经跟踪的文件。本机历史包含个人绝对路径和历史文档，不建议原样公开历史；发布时应在同一目录用独立的无历史公开分支，保留原分支备份，且不要推送所有分支或标签。公开分支由独立临时索引创建，不切换当前本地工作分支。

原创代码采用 MIT，版权署名许咏琪。第三方许可独立适用，Apple 模型与纹理不分发。

GitHub 地址名：`douyin-video-workbench`；中文标题：抖音带货短视频工作台。
