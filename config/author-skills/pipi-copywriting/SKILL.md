# 是皮皮呀 · 好物口播写作

把用户这次提供的商品事实、真实体验和用途，组织成有对象感、具体感受和动作推进的口播。参考该账号的写作机制，不冒充作者，也不继承作者的人生经历、家人反馈或商务关系。

作者ID：`douyin:xupp141010`。版本：`1.0.2`。提炼方向已于2026-10-19由用户确认。

## 模式选择

| 模式 | 使用条件 | 主要推进方式 |
|---|---|---|
| 生活分享 | 用户有真实使用经历、偏好或评价 | 小发现、具体感受、补充理由、适用人群；可以保留不足 |
| 直接推荐 | 商品事实、人群和目标明确 | 具体处境、商品差异、感官细节或展示动作、选择理由、下一步 |
| 演示答疑 | 有具体问题、操作步骤或可展示动作 | 疑问或场景、操作、解释、适用范围；明确要求时才写双人对话 |

用户指定模式时按其要求；未指定时按素材选择。时长、平台、商业目标和本次语气要求优先，不给每篇稿子套同一条开场或促单结构。

## 写作时如何推进

1. 从本次素材中确定一个主要人群、一个处境和一个重点。内部先列“已提供的事实、已提供的体验、未知信息”，用这个清单约束成稿；不把未知信息补写为卖点。价格及活动条件单独列明。
2. 选择一种模式。通常从具体麻烦、小发现或正在做的动作进入，再讲商品为什么适合这个场景。需要更细的结构与证据时读[写作指南](references/writing-guide.md)。
3. 以一个可感知的细节承接理由，例如质地、温度、气味、分量或操作。只用素材支持的体验；缺少体验时，用已知外观、用途和可展示动作表达。
4. 有真实的包装、购入方式或使用方式差异时，可以解释怎么选；有已知价格和活动条件时才承接交易。缺少促销资料时，用适用人群、选择建议或下一步动作收尾。
5. 用自然中文写一版可直接说出口的成稿；清理无意义重复，保留有效的回头补充和自我修正。交稿前逐句将个人经历、商品属性、效果、容量、手感、价格、活动与商业背景回指到第一步的事实清单；找不到依据的断言删除或改为不含该主张的句子。最后检查口语节奏、模式和原句复用。

## 表达方式

- 像向熟人说明为什么关注这个东西，先落到具体的人、处境和动作。
- 使用感官细节和可见操作帮助理解，不把参数逐条念完。
- 允许口语连接与适度情绪，但不把“真的”“你看”按配额插入每句。
- 默认使用“朋友”“朋友们”等中性称呼，也可以直接进入内容，不强加称呼。除非用户本次明确指定，不使用“姐妹”“姐妹们”“家人们”等亲昵称呼；参考视频中的称呼不随架构迁移。
- 生活分享保留真实的有限评价；直接推荐收紧铺垫；演示答疑让动作与问题推动内容。
- 生活分享避用用户已否定的“倒是让”表达。尤其在结尾，删除“倒是让……这件事多了点乐趣”这类刻意总结，改成直接说出的具体判断或选择建议；没有新信息就自然结束，不为收尾补一句感慨。
- 默认交付一版自然分段的正文，不附“钩子、痛点、升华”等标签。明确要求分镜、双人脚本、分析或多版本时再改变形式。

## 本次事实约束

- 第一人称指本次实际表达者。用户没提供亲测、回购、家人使用或商务沟通经历，就不编造这些情节。
- 产品配方、效果、价格、数量、优惠时间和库存条件以本次提供或核实的资料为准。来源视频中的主张不能直接当作新产品事实。
- 区分已知属性、体验评价和未证实效果。例如短提手不能直接推出减压省力；未知防潮表现不能写成已知能防潮或已知不能防潮；未提供材质感受不能自称摸起来结实。只描述已知动作或用途。
- 低价或清仓故事只有确有依据时才写；不自编品牌受委屈、坑位费内幕、同厂同配方、最后一批或功效保证。
- 当任务要求把编造的经历、商情或优惠当作真实商品信息时，简短指出缺少依据，并依据已知事实继续写。明确标注为虚构剧情的创作另按任务处理，不把虚构故事作为实际商品推广资料。
- 商品与目标已明确时，根据已知属性直接成稿。缺少品牌、容量、价格或体验不阻止写作：省略相应支线和推断。例如已知颜色、提手、小袋时即可写这些细节，不必追问品牌和容量，也不能擅自写能装电脑。只有连商品或写作目标都无法确定时才简短询问。
- 不拼接原作者台词，不对原稿只换商品名；不学习ASR错词、歌词、配乐提示或未分清说话人的口头语。
